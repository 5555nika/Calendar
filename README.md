# Event Calendar  App

A professional  Event Calendar application built with React, TypeScript, and Redux.
This project allows users to manage personal events, assign them to guests, and view them in an interactive calendar interface.

## Features

- User Authentication: Secure login system with Redux state management.
- Event Management: Create, filter, and view events by date.
- Interactive Calendar: Visual event representation using Ant Design.
- Data Persistence: Events and user sessions are persisted using localStorage.
- Responsive Design: OPtimized for both desctop and mobile deviced.

  ## Tech Stack
- Frontend: React, TypeScript
- State Management: Redux
- UI Components: Ant Design(antd)
- Date Management: Dayjs
- Routing: React-router-dom
